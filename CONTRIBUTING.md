# Contributing to NBO

Thank you for your interest in NBO.

## Issues are welcome

If something is broken, unclear or missing, please open an issue. Say what you ran, what you expected and what happened instead. Logs and the NBO version help a lot. Never paste a secret, a token or a kubeconfig into an issue.

## Code contributions are not accepted yet

NBO does not accept outside pull requests or patches for now. This keeps the licensing simple while the project is young: NBO is published under the Functional Source License (see `LICENSE.md`), and every line of it has one copyright holder.

When contributions open, each contributor will be asked to sign a short contributor agreement first, so that contributed code can be released under the same license as the rest of NBO. This file will say how when that happens.
